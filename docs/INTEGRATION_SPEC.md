# Minds10 Skills Integration Specification

## Pipeline

1. Input Intelligence — classify input and missing context.
2. Research — user sources first, optional Gemini Google Search second.
3. Knowledge — normalize claims, evidence, examples, caveats, unknowns.
4. Audience + Strategy — why-care, angle, promise, transformation.
5. Story Architecture — situation, tension, discovery, turn, payoff.
6. Retention Planning — causal momentum, curiosity gaps, re-hooks, payoffs.
7. Hook — three candidate hooks, select the strongest honest one.
8. Script — spoken Egyptian Arabic draft sized to requested duration.
9. Humanization — rewrite only for natural rhythm and speech.
10. Anti-Slop Review — analyze/score/identify/minimal fixes.
11. Final Human Review — watch as a viewer and identify drop points.
12. Final Editor — apply minimal effective fixes and preserve facts/voice.

## Non-conflict rules

- No Skill may invent factual content.
- Humanization cannot add information.
- Retention cannot remove factual qualifications for drama.
- Anti-Slop identifies problems before rewriting.
- Final Editor owns the final prose rewrite so the script is not rewritten repeatedly.
- Voice DNA is style guidance, never text copying.
- Egyptian Arabic is a register choice, not a license for slang overload.
