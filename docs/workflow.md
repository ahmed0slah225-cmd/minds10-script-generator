# Workflow

أي مشروع يبدأ بتحليل المهمة. الطلبات التي تحتوي على نطاق صفحات تُحفظ كنطاق صريح. في مهام الفيديو يتم تشغيل research/knowledge/strategy/hook/story/script/humanization/review/final.


## سياسة البحث

- `use_web_search = true`: يمكن استخدام Google Search أثناء مرحلة البحث.
- `use_web_search = false`: ممنوع Google Search تمامًا.
- عند وجود روابط أدخلها المستخدم، يمكن استخدام URL Context لقراءة هذه الروابط تحديدًا حتى مع إغلاق البحث العام.
- عند إغلاق البحث العام وعدم وجود روابط مستخدم، لا يتم تنفيذ نداء بحث خارجي أصلًا؛ يستمر خط الإنتاج اعتمادًا على الفكرة وملفات المشروع والمصادر المرفوعة.

## اختيار الموديل

المستخدم يختار لكل جلسة بين `gemini-3.7-flash` و`gemini-3.6-flash`. الاختيار يؤثر على استدعاءات Gemini في خط الإنتاج ولا يلغي سياسة البحث.
