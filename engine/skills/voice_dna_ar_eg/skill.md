# Skill: voice_dna_ar_eg

## الوظيفة
استخراج بصمة أسلوبية منظّمة من عينات كتابة سابقة للمستخدم، واستخدامها
كطبقة توجيه أسلوبي مشتركة عبر باقي الـ Engines. **الهدف استخراج أنماط،
مش نسخ نص بعينه.** ممنوع تمامًا تكرار جمل حرفية من العينات داخل سكريبت
جديد.

## يتم استدعاؤها من
1. **الاستخراج** (مرة واحدة لكل بصمة): `engine/engines/voice_dna.py`
   عند إضافة/تحديث عينات في صفحة "Voice DNA".
2. **الاستخدام أثناء التخطيط والكتابة**: تُمرَّر نتيجة الاستخراج
   (`VoiceProfile`) كسياق لـ `hook`, `story_architecture`, `script_writer`,
   `humanize`.
3. **المراجعة النهائية**: `voice_dna_consistency_check` — تتأكد إن
   السكريبت النهائي لسه متماشي مع البصمة المستخرجة.

## Input Contract (الاستخراج)
- قائمة نصوص سابقة للمستخدم (سكريبتات، مقالات، منشورات، تفريغ فيديوهات).

## Output Contract (الاستخراج)
كائن `VoiceProfile` منظم (انظر engine/models.py) يغطي:
طول الجمل، إيقاع الكلام، استخدام الأسئلة، شكل الحوار مع المشاهد،
المفردات المميزة، درجة العامية، درجة العاطفة، طريقة شرح الأفكار،
طريقة بناء الأمثلة، شكل الانتقالات، طريقة بناء الفضول، طريقة إنهاء
الفكرة، استخدام التشبيهات، مستوى الرسمية، درجة التلقائية، طريقة
مخاطبة المشاهد.

يُضاف أيضًا `raw_traits_summary`: فقرة حرة (5-8 أسطر) تلخّص "شخصية"
الكاتب الكتابية، تُستخدم كسياق سريع في الـ prompts بدل تمرير كل الحقول
كل مرة.

## Output Contract (فحص الاتساق النهائي)
```
{
  "consistent": true/false,
  "drift_points": [
    {"location_hint": "...", "issue": "ابتعد عن مستوى العامية المعتاد", "suggestion": "..."}
  ]
}
```

## قواعد التشغيل
1. الاستخراج وصفي فقط — لا تصدر أحكام قيمية ("أسلوب ضعيف/قوي")، فقط
   وصف للأنماط الفعلية.
2. الاستخدام في الكتابة توجيهي — "اكتب بجمل يغلب عليها القصر مع سؤال
   داخلي بين الحين والتاني"، مش "انسخ من العينة رقم 3".
3. ممنوع نسخ جملة كاملة من عينة سابقة داخل سكريبت جديد، حتى لو الجملة
   مناسبة للموضوع.
4. لو تعارضت البصمة مع قاعدة أسلوبية عامة في المشروع (مثال: البصمة فيها
   عامية كثيفة جدًا لكن قاعدة المشروع تمنع المبالغة)، الأولوية لقواعد
   المشروع العامة، مع محاولة أقرب توافق ممكن مع البصمة.
5. لو معندش المستخدم بصمة محفوظة، الـ Engines تستخدم أسلوب افتراضي:
   "عامية مصرية طبيعية، جمل متوسطة الطول، أسئلة داخلية بين الحين
   والتاني، بدون رسمية زايدة" — بدون اعتبار ده بصمة ثابتة.

## ما لا يجوز لها فعله
- لا تقلّد كاتب يوتيوب مشهور بعينه — الاستخراج يكون من عينات المستخدم
  نفسه فقط.
- لا تحوّل البصمة لقائمة قواعد جامدة تتكرر بنفس الصياغة في كل سكريبت —
  البصمة اتجاه أسلوبي، مش قالب حرفي.
