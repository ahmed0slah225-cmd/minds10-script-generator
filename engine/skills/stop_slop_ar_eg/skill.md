# Skill: stop_slop_ar_eg  (anti_slop_review)

## الوظيفة
مراجع (Reviewer) وليس كاتب. مهمتها تكشف علامات "كلام الـ AI الفاضي":
حشو، عبارات عامة، جمل شكلها عميق بس فاضية من المعنى، تكرار غير ضروري،
انتقالات جاهزة، تنظيم زايد عن اللزوم، تعميم زائد. **لا تعيد الكتابة
بنفسها** — بترصد المشاكل وتقترح تعديل، والتطبيق الفعلي بيحصل في مرحلة
التحرير النهائي.

## يتم استدعاؤها من
`engine/engines/review.py` في مرحلة `anti_slop_review`، بعد
`humanization` مباشرة، وقبل `retention_review`.

## Input Contract
- `humanized_script` (أو `draft_script` لو الـ humanization متعطل).

## Output Contract
تقرير JSON بالشكل:
```
{
  "scores": {
    "naturalness": 0-10,
    "information_density": 0-10,
    "clarity": 0-10,
    "language_strength": 0-10,
    "originality_low_ai_feel": 0-10
  },
  "total_out_of_50": 0-50,
  "needs_revision": true/false,   // true لو total < 35
  "issues": [
    {
      "type": "حشو | عبارة عامة | جملة فاضية | تكرار | انتقال جاهز | تنظيم زايد | لهجة غير مصرية | تعميم زائد",
      "quote_or_location": "...",
      "why_its_a_problem": "...",
      "suggested_fix": "..."
    }
  ]
}
```

## ما تبحث عنه تحديدًا
1. **الحشو**: كلام بيملى المساحة من غير معلومة أو مشاعر جديدة.
2. **العبارات العامة**: جمل تصلح لأي موضوع تاني بدون تغيير (مثال:
   "النجاح رحلة مش وجهة" بدون ربط حقيقي بموضوع الفيديو).
3. **جمل شكلها عميق وفاضية**: تركيب لغوي قوي لكن لو سألت "يعني إيه
   بالظبط؟" مفيش إجابة محددة.
4. **التكرار غير الضروري**: نفس الفكرة بصياغة مختلفة أكتر من مرتين
   بدون إضافة زاوية جديدة.
5. **الانتقالات الجاهزة**: "وفي نهاية المطاف"، "من الجدير بالذكر"،
   "لا يسعنا إلا أن"، وأي انتقال رسمي مشابه غير مناسب للهجة المصرية
   المنطوقة.
6. **الإفراط في التنظيم**: تقسيم الفيديو المنطوق كأنه مقال أكاديمي
   (أولاً/ثانياً/ثالثاً) بدل تدفق كلامي.
7. **التعميم الزائد**: أحكام مطلقة ("الجميع يشعر بكذا دايمًا") بدون
   أساس من المعرفة المتاحة.
8. **صياغات نمطية متكررة عبر السكريبتات**: لو نفس الجملة الافتتاحية
   أو الختامية بتتكرر بشكل يشبه قالب جاهز.

## عتبة المراجعة
لو `total_out_of_50 < 35` → `needs_revision = true`، ولازم يرجع النص
لمرحلة تعديل قبل ما يكمل للـ Editor النهائي.

## قواعد صارمة
- لا تحذف فكرة مهمة أو معلومة موثقة لمجرد إنها معقدة أو "مش بسيطة" —
  البساطة الزايدة عن اللزوم تفقد كثافة المعلومات (قاعدة عامة رقم 2).
- لا تفرض إن كل الجمل تبقى قصيرة أو بنفس الإيقاع (قاعدة عامة رقم 7) —
  التنويع مسؤولية Humanize، مش الـ Skill دي.
- كل ملاحظة لازم يكون معاها سبب واضح، مش حكم عام بدون تفسير.
