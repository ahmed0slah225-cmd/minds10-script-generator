# Minds10 — مولد سكريبتات YouTube

منصة Streamlit لبناء سكريبتات YouTube طويلة بالعربية المصرية باستخدام Gemini، مع Architecture قابلة للتوسع بالـEngines والـSkills.

## إعداد Streamlit Secrets
أضف:

```toml
GEMINI_API_KEY = "ضع_المفتاح_هنا"
```

## الموديلات
- Gemini 3.8 Flash — الافتراضي.
- Gemini 3.7 Flash — متاح للاختيار.
- Gemini 3.6 Flash — متاح للاختيار.
- Gemini 3.5 Flash — متاح للاختيار.

## التعامل مع 429 / quota
إذا نفدت حصة موديل محدد، يحاول الـProvider تلقائيًا الموديلات المسجلة التالية قبل إيقاف التشغيل. إذا انتهت الحصة اليومية للمشروع على الموديلات المتاحة، يجب انتظار إعادة ضبط RPD أو ترقية المشروع إلى Paid Tier في Google AI Studio.

## البحث المباشر
`تفعيل البحث المباشر من الإنترنت` مغلق افتراضيًا.

عند إيقافه لا يتم تفعيل Google Search tool.
عند تشغيله يمكن للنموذج استخدام البحث وفق عمق البحث المحدد.

## تشغيل محلي
```bash
pip install -r requirements.txt
streamlit run app.py
```

## فلسفة الكتابة
المشروع مبني على فهم الموضوع قبل الكتابة، والاحتفاظ القائم على الاكتشاف، والقصص التي تخدم الفكرة، واللغة المصرية القابلة للنطق، والـHumanization المقيد بالحقائق، ومراجعة Anti-Slop قبل التحرير النهائي.

راجع `ARCHITECTURE.md` ومجلد `skills/` لفلسفة النظام.
