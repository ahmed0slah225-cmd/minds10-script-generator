# 🎬 Minds10 Script Generator — خط إنتاج كامل

تطبيق Streamlit بيحوّل كتابة سكريبت يوتيوب من "زرار واحد يطلعلك سكريبت"
إلى **خط إنتاج كامل على مراحل**، كل مرحلة بتقدر تراجعها وتعدّلها قبل ما
تكمل للي بعدها، وكل حاجة مبنية على **مصادر انت بتحددها** بدل الاعتماد
على بحث حي على الإنترنت.

## 🏗️ خط الإنتاج

```
الموضوع
   ↓
مصادر ومراجع (قاعدة معرفة خاصة بيك — كتب / مقالات / أبحاث / ملاحظات)
   ↓
استخراج المعرفة (فكرة أساسية، نقاط، قصص، أرقام، اقتباسات، محتاج تحقق)
   ↓
بناء الـ Outline (Hook → مشكلة → فضول → قصة → تفسير → مثال → مفاجأة → حل → تطبيق → نهاية)
   ↓
توليد 10 هوكس + تقييمهم (فضول / قوة أول جملة / فتح Loop / عدم كشف الإجابة / احتفاظ)
   ↓
كتابة السكريبت جزء جزء (مع مراجع احتفاظ بعد كل جزء)
   ↓
فريق مراجعين: هوك • احتفاظ • تدقيق حقائق • أسلوب
   ↓
تحرير نهائي (المحرر يدمج كل الملاحظات في نسخة واحدة)
   ↓
السكريبت النهائي + مصادر كل معلومة + اقتراحات B-roll وتعليمات مونتاج
```

## 📁 هيكلة المشروع

```
minds10-script-generator/
├── app.py                      # واجهة Streamlit — خط الإنتاج كامل، مقسّم لمراحل
├── SCRIPT_RULES.md             # ⭐ شخصية القناة وقواعد الأسلوب — عدّل هنا فقط
├── engine/
│   ├── __init__.py
│   ├── rules.py                 # بيقرا/يحفظ SCRIPT_RULES.md
│   ├── knowledge_base.py        # قاعدة المعرفة: رفع مصادر، تخزين، بحث بسيط
│   ├── gemini_client.py         # طبقة موحّدة لنداءات Gemini (نص/JSON + retry)
│   ├── prompts.py                # كل الـ Prompts لكل مرحلة من مراحل الإنتاج
│   ├── pipeline.py               # الدوال اللي بتنفّذ كل مرحلة فعليًا
│   └── style_guide.md            # نسخة مطوّلة وقابلة للقراءة من الأسلوب (مرجع بشري)
├── examples/
│   └── sample_script.md          # مثال مرجعي (Few-shot) قديم للأسلوب واللغة
├── knowledge/                    # مكان مقترح لحفظ مصادرك كملفات (اختياري)
├── .streamlit/
│   └── secrets_template.toml
├── requirements.txt
├── .gitignore
└── README.md
```

## ⭐ SCRIPT_RULES.md — أهم ملف في المشروع

كل مراحل خط الإنتاج (الاستخراج، الهيكل، الهوكس، الكتابة، مراجعة
الأسلوب، التحرير النهائي) بتقرأ `SCRIPT_RULES.md` مباشرة قبل ما تشتغل.
عايز تغيّر شخصية القناة؟ عدّل الملف ده بس — من داخل الواجهة (في
الشريط الجانبي فيه محرر مدمج) أو من الكود مباشرة. مفيش داعي تلمس أي
Python.

الملف بيحتوي كمان على قسمين إضافيين اتبنوا بالاستفادة من مجموعة
Claude Skills متخصصة في جودة الكتابة (humanize، addictive-writing،
stop-slop، general-writing) بعد ترجمتها وتكييفها للعامية المصرية:
- **ضد الكتابة الآلية**: قائمة أنماط وعبارات "ريحة الـ AI" الشائعة
  (مبالغات جاهزة، خواتيم نمطية، تعداد مصطنع...) ممنوع تظهر في السكريبت.
- **الكتابة الجاذبة**: مبادئ الاحتفاظ الحقيقي (سبب→نتيجة، فضول
  مفتوح، إعادة تشويق دورية) من غير تشويق كاذب أو مبالغة.

## 🤖 مراجع الطبيعية (المرحلة ٦)

مراجع خامس بجانب الهوك/الاحتفاظ/الحقائق/الأسلوب، بيقيّم السكريبت على
٥ أبعاد (المباشرة، الإيقاع، الثقة بالمشاهد، الطبيعية، الكثافة) كل
واحد من ١٠، ويرصد أي نمط كتابة "آلي" مع اقتراح تعديل له. مبني على نفس
منهج تقييم AI-slop من مجموعة skills المذكورة فوق.

## 🧠 زوايا تفكير أعمق (المرحلة ٢)

مرحلة استخراج المعرفة بقت كمان بتطلع "زوايا تفكير أعمق" غير المتوقعة
باستخدام أطر تفكير معروفة (عكس الفكرة، الدفاع عن الرأي المضاد، الأثر
بعيد المدى، تشبيه جديد) عشان السكريبت مايبقاش سرد عام للمعلومات
المعروفة، ده بالاستفادة من فكرة "Deep Thinking frameworks".

## 🎙️ بصمة الصوت (Voice DNA)

لو رفعت سكريبتات أو كتابات سابقة بتاعتك في قاعدة المعرفة (المرحلة ١)
ونوّعتها كـ **"عينة من أسلوبك الشخصي"**، مرحلة كتابة الأجزاء (المرحلة
٥) هتحاول تقلّد إيقاع جملك ومفرداتك المفضّلة بدل ما تكتب بصوت عام —
من غير ما تنسخ نفس الجمل حرفيًا.

## 📚 قاعدة المعرفة (بدل البحث الحي على الإنترنت)

بدل ما يعتمد التطبيق على بحث Google المباشر (Grounding) واللي بيحتاج
Billing مفعّل وبيرجع أحيانًا معلومات مش دقيقة، الفكرة بقت:

1. انت بترفع مصادرك (PDF / TXT / MD) أو تلصق ملاحظاتك مباشرة في
   المرحلة الأولى.
2. مرحلة "استخراج المعرفة" بتقرا المصادر دي بس وتطلع منها الفكرة
   الأساسية، النقاط، القصص، الأرقام، الاقتباسات — ومفيش حاجة بتتخترع.
3. مرحلة "تدقيق الحقائق" في الآخر بتتأكد إن كل رقم أو اقتباس في
   السكريبت النهائي فعلًا موجود في مصادرك، وترصد أي حاجة غير موثّقة.

لو معندكش مصادر لموضوع معيّن، تقدر تكمل من غيرها — بس السكريبت هيكون
أعم وهيتجنّب الأرقام والدراسات المحددة بدل ما يخترعها.

## 🚀 التشغيل محليًا

```bash
git clone https://github.com/<اسم_حسابك>/minds10-script-generator.git
cd minds10-script-generator
pip install -r requirements.txt

cp .streamlit/secrets_template.toml .streamlit/secrets.toml
# افتح .streamlit/secrets.toml وحط مفتاح Gemini API الحقيقي بتاعك

streamlit run app.py
```

## ☁️ النشر على Streamlit Community Cloud

نفس خطوات النسخة السابقة بالظبط:
1. [share.streamlit.io](https://share.streamlit.io/) → **New app**.
2. اختار الـ repo والـ branch `main` وملف `app.py`.
3. **Deploy**، وبعدين من **Settings → Secrets** ضيف:
   ```toml
   GEMINI_API_KEY = "مفتاحك_الحقيقي_هنا"
   ```

## 🔑 إزاي تجيب مفتاح Gemini API

1. [Google AI Studio](https://aistudio.google.com/) → **Get API key** → **Create API key**.
2. انسخ المفتاح واستخدمه في `secrets.toml` أو في Secrets على Streamlit Cloud.

## ⚠️ ملاحظات مهمة

- **متحطش مفتاح الـ API مباشرة في الكود** — استخدم Secrets دايمًا.
- `.streamlit/secrets.toml` الحقيقي متضاف في `.gitignore`.
- كل مرحلة في خط الإنتاج بتستخدم استدعاء API منفصل، يعني سكريبت واحد
  بياخد أكتر من نداء (استخراج + هيكل + هوكس + كل جزء + 4 مراجعين +
  تحرير نهائي + B-roll) — طبيعي إن ده ياخد وقت أطول من النسخة القديمة
  بس النتيجة أدق وأقرب لأسلوبك ومبنية على مصادر حقيقية.
- أسامي الموديلات بتتغيّر من وقت للتاني — لو قابلت خطأ 404 غيّر
  الموديل من الشريط الجانبي.
