# 🎬 Minds10 Script Generator

تطبيق Streamlit بيكتبلك سكريبت فيديو يوتيوب كامل (حوالي 30 دقيقة) بالعامية
المصرية، عن طريق **Pipeline من 13 عقل متخصص** (مش نداء واحد للنموذج)،
كل عقل شغلته حاجة واحدة بس، وبعده يسلّم شغله للعقل اللي بعده. في الآخر،
عندك **ذاكرة دائمة** (قاعدة بيانات Turso) بتفتكر كل الهوكات اللي اتكتبت
قبل كده لكل موضوع، عشان النموذج ميكررش نفس الصياغة تاني حتى لو رجعت
تستخدم التطبيق بعد أيام.

## الـ13 عقل بالترتيب

| # | العقل | شغلانته |
|---|-------|---------|
| 1 | محلل الموضوع | يستخرج جوهر الموضوع والمشاعر المرتبطة بيه |
| 2 | فاهم الأفكار الرئيسية | يطلّع 4-6 زوايا/أفكار ممكنة |
| 3 | باحث المعلومات | بحث مجاني حقيقي (DuckDuckGo) + تلخيص |
| 4 | ليه الناس تهتم بالموضوع | يحدد الألم/الرغبة الحقيقية عند المشاهد |
| 5 | باني هيكلة الفيديو | يبني عدد الأجزاء المناسب لمدة الفيديو |
| 6 | كاتب الهوك | يكتب 3 هوكات ويختار الأقوى (بعيد عن أي هوك سابق) |
| 7 | الناقد والمعترض | يعترض على الهوك والهيكل ويحسّنهم |
| 8 | مقالات منشورة عن الموضوع | بحث مجاني بزاوية "آراء ومقالات" |
| 9 | كاتب السكريبت الكامل | يكتب السكريبت كامل بناءً على كل ما سبق |
| 10 | محافظ على الجمهور | يقوّي نقاط الشد والتشويق في كل السكريبت |
| 11 | مراجع التكرارات | يتأكد مفيش تكرار داخلي أو مع سكريبتات سابقة |
| 12 | محرر اللهجة العامية | يظبط العامية المصرية الطبيعية |
| 13 | المراجع النهائي | يقرأ كمشاهد ويطلع النسخة النهائية |

كل عقل من دول له **تعليمات افتراضية جاهزة** في `pipeline.py`
(`DEFAULT_PROMPTS`)، وتقدر تعدلها من واجهة التطبيق نفسها (شريط جانبي ->
"تخصيص تعليمات العقول الـ13") قبل كل توليد من غير ما تلمس الكود خالص.

## بنية المشروع

- `app.py` — واجهة Streamlit، عرض النتيجة، التحميل.
- `pipeline.py` — كل الـ13 عقل وتعليماتهم الافتراضية ومنطق تشغيلهم بالترتيب.
- `database.py` — الاتصال بذاكرة Turso الدائمة (حفظ/قراءة الهوكات السابقة).
- `research.py` — البحث المجاني على الإنترنت (DuckDuckGo عبر مكتبة `ddgs`).

## ⚠️ التكلفة: 13 نداء API لكل سكريبت

كل توليد سكريبت = **13 نداء منفصل لـ Gemini API** (مش نداء واحد)، يعني:
- وقت التوليد أطول (تقريبًا دقيقة لدقيقتين، مش نص دقيقة).
- استهلاك الحصة اليومية (Quota) أسرع بـ13 ضعف.

**الخبر الحلو:** ولا عقل واحد من الـ13 بيستخدم خاصية Google Grounding
المدفوعة - عقل "باحث المعلومات" وعقل "مقالات منشورة عن الموضوع" بس هما
اللي بيعملوا بحث، وبيستخدموا DuckDuckGo المجاني 100%. يعني الـ Pipeline
كله شغال على الخطة المجانية العادية لـ Gemini من غير أي حاجة لها علاقة
بتفعيل Billing - بس الحصة اليومية المجانية (Requests Per Day) هتخلص أسرع
من لما كان نداء واحد بس، فلو بتولّد كذا سكريبت في نفس اليوم ممكن تقابل
رسالة 429 عادية (راجع قسم "ملاحظات" تحت).

## 1) هات مفتاح Gemini API (مجاني)

1. ادخل على [Google AI Studio](https://aistudio.google.com/apikey).
2. سجل دخول بحساب Google بتاعك.
3. اضغط **Create API key** وانسخ المفتاح.

---

## 2) اعمل قاعدة بيانات Turso مجانية (للذاكرة الدائمة - اختياري)

الخطوة دي اختيارية؛ لو تخطيتها التطبيق هيشتغل عادي بس من غير ذاكرة بين
الجلسات (يعني ممكن يكرر نفس الهوك لو رجعت تستخدمه بعد أيام).

1. ادخل على [app.turso.tech/signup](https://app.turso.tech/signup) وسجل
   حساب (بـ GitHub أو Google، مش فارق للاستخدام ده).
2. من لوحة التحكم، اعمل **Create Database**، سمّيها أي اسم (مثلاً
   `minds10-history`) واختار أقرب منطقة ليك.
3. بعد ما تتعمل، هتلاقي **Database URL** (بيبدأ بـ `libsql://`) —
   انسخه.
4. اعمل **Create Token** (أو من تبويب "Tokens")، وانسخ التوكن اللي
   هيطلعلك (بيتقالك مرة واحدة بس، فاحفظه فورًا).

هتحتاج القيمتين دول (URL والتوكن) في الخطوة الجاية.

---

## 3) شغّل المشروع على جهازك (اختياري، للتجربة)

```bash
git clone https://github.com/<اسم_حسابك>/minds10-script-generator.git
cd minds10-script-generator
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt

cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# افتح الملف وحط مفتاح Gemini، وحط TURSO_DATABASE_URL و TURSO_AUTH_TOKEN
# لو عايز الذاكرة الدائمة (أو سيبهم زي ما هما لو مش عايزها)

streamlit run app.py
```

## 4) ارفع الكود على GitHub

```bash
git init
git add .
git commit -m "أول نسخة من مولد السكريبتات"
git branch -M main
git remote add origin https://github.com/<اسم_حسابك>/minds10-script-generator.git
git push -u origin main
```

> تأكد إن ملف `.streamlit/secrets.toml` (اللي فيه المفاتيح الحقيقية) **مش**
> بيترفع؛ ملف `.gitignore` متظبط عشان يمنع ده تلقائيًا.

---

## 5) انشر على Streamlit Community Cloud

1. ادخل على [share.streamlit.io](https://share.streamlit.io) وسجل دخول
   بنفس حساب GitHub.
2. اضغط **New app**، اختار الـ repo والـ branch `main` والملف `app.py`.
3. من **Settings -> Secrets**، ضيف:

   ```toml
   GEMINI_API_KEY = "مفتاحك_الحقيقي_هنا"
   TURSO_DATABASE_URL = "libsql://اسم-قاعدتك.turso.io"
   TURSO_AUTH_TOKEN = "التوكن-بتاعك"
   ```

4. اضغط **Deploy**.

---

## 6) إزاي تستخدم التطبيق

1. اكتب موضوع الفيديو (والجمهور والنبرة والمعلومات الإضافية لو حابب).
2. اضغط "اكتب السكريبت عبر الـ13 عقل" واستنى - هتشوف كل عقل بيشتغل
   لوحده لحظة بلحظة في شاشة التقدم.
3. بعد ما يخلص، هتلاقي: السكريبت النهائي، ملاحظات المراجعة الأخيرة،
   المصادر اللي اتلقت، ومخرجات كل عقل بالتفصيل لو عايز تفهم إزاي وصل
   للنتيجة دي.
4. حمّل السكريبت كـ TXT أو Word.

## ملاحظات

- عدد الكلمات بيتحسب تقريبيًا على أساس ~145 كلمة في الدقيقة للعامية
  المصرية.
- لو قابلت خطأ 429 (تجاوز الحصة)، استنى الحصة اليومية ترجع تتصفر، أو
  فعّل الفوترة (Billing) على Google AI Studio لحصة أكبر بكتير.
- عايز تغيّر سلوك أي عقل بشكل دائم (مش بس لتوليد واحد)؟ عدّل
  `DEFAULT_PROMPTS` في `pipeline.py`.
- الذاكرة الدائمة بتتطابق مع الموضوع بالنص الحرفي اللي كتبته - لو غيّرت
  صياغة الموضوع شوية بين مرة وتانية، ممكن التطابق ميحصلش والعقول
  مايشوفوش الهوكات السابقة.
