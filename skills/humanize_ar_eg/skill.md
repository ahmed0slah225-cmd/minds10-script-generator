# humanize_ar_eg

**الأصل:** `harshaneel/humanize` — مبني على 9 روافع للكتابة البشرية (مش مجرد قائمة كلمات ممنوعة)، معاد صياغته بالكامل كنسخة عربية مصرية لسكريبتات يوتيوب منطوقة (مش مقال مكتوب).

**النوع:** Rewrite (إعادة صياغة فعلية) — نداء Gemini واحد فقط لكل سكريبت.

## متى تعمل

مرحلة "Humanization" في الـWorkflow: بعد `Script Writing` مباشرة، وقبل `Anti-Slop Review`.

## Input Contract

```
HumanizeSkill.run(script_text: str, voice_dna_fragment: str = "", known_facts: list[str] | None = None)
```

## Output Contract

```json
{
  "humanized_text": "النص الكامل بعد الأنسنة",
  "levers_applied": ["اسم الرافعة المستخدمة", "..."],
  "change_log": [{"before": "اقتباس <15 كلمة", "after": "اقتباس <15 كلمة", "why": "..."}]
}
```

## الروافع التسعة (مُكيّفة للمصري المنطوق)

1. **تنويع إيقاع الجملة** — مش كل الجمل بنفس الطول.
2. **تفاصيل ملموسة** — لكن فقط لو مدعومة من السياق الموجود بالفعل.
3. **التردد الطبيعي** — "يعني"، "بصراحة"، وقفة قبل فكرة مهمة.
4. **مخاطبة مباشرة** — "إنت" مش "الشخص" أو "المرء".
5. **أسئلة داخلية** — بدل الجزم المطلق طول الوقت.
6. **مفردات يومية** — بدل المصطلحات الرسمية اللي محدش بيقولها فعليًا.
7. **انتقالات كلامية** — مش "علاوة على ذلك"، لكن سؤال أو ربط طبيعي.
8. **الاعتراف بالتعقيد** — مش كل حاجة حل بسيط وسهل.
9. **إيقاف الجملة المثالية** — سيبها تتنفس، مش كل جملة مقفولة بإحكام.

## ما لا يجوز فعلها

- لا تضيف معلومة/حدث/تجربة شخصية غير موجودة في النص الأصلي.
- لا تغيّر المعنى أو تحذف معلومة.
- لا تبالغ في العامية لدرجة الخروج عن الطبيعية.
- لا تسطّح كل الجمل لنفس الطول (عكس الهدف من الروافع).

## طريقة الاستدعاء

تُستدعى من `engine/humanization_engine.py` مرة واحدة فقط لكل سكريبت.
