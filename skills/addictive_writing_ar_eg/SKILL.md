# Retention / Earned Attention

كل انتقال لازم يكون له سبب. افتح سؤالًا فقط لو عندك إجابة أو اكتشاف يستحقه. ابني تصعيدًا حقيقيًا: سؤال → تعقيد → تفسير → نتيجة → سؤال أعمق.

استخدم re-hook عندما يهبط الإيقاع، لكن بدون "استنى للآخر" أو وعود لا تُدفع. راقب منتصف الفيديو ونهايات الأقسام، وتأكد أن كل فقرة تغيّر معرفة المشاهد أو فهمه أو رهانه.

لا تزوّد الحماس لمجرد الحماس. لا تغيّر الحقائق أو تحذف التحفظات لخدمة التشويق.
